# PyJWT вместо python-jose. Последняя не обновлялась с 2021 года: путаница
# алгоритмов, отказ в обслуживании через JWE с высокой степенью сжатия. Вместе
# с ней приезжала ecdsa, где уязвимость к атаке по времени объявлена
# неустранимой — авторы пишут, что чистый Python не даёт постоянного времени
# выполнения, и чинить не планируют.
#
# Нам нужен только HS256, так что ecdsa не требовалась вовсе.
# Без extras: cryptography нужна PyJWT только для RSA и ECDSA, а у нас HS256 —
# там достаточно hmac из стандартной библиотеки. Отказ от неё убирает из
# зависимостей ещё и несколько известных проблем самой cryptography.
#
# Вместе с python-jose уходят ecdsa, rsa и pyasn1: первая с неустранимой
# уязвимостью к атаке по времени, у последней три отдельные находки.
